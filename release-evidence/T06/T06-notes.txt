HOW TO RE-RUN THE LIVE-PG SUITE
  export PGBIN=/usr/lib/postgresql/16/bin PGDATA=$PWD/.tmp-pg/t06 PGPORT=55462
  runuser -u postgres -- "$PGBIN/initdb" -D "$PGDATA" -U redai --auth=trust
  runuser -u postgres -- "$PGBIN/pg_ctl" -D "$PGDATA" \
      -o "-p $PGPORT -k /tmp -c listen_addresses=127.0.0.1" -w -l "$PGDATA/log" start
  export DATABASE_URL="postgres://redai@127.0.0.1:55462/postgres"
  pnpm exec vitest run packages/application/src/projects apps/api/src/projects
  runuser -u postgres -- "$PGBIN/pg_ctl" -D "$PGDATA" stop -m immediate ; rm -rf "$PWD/.tmp-pg"
  (Without DATABASE_URL the DB suite SKIPS LOUDLY; unit + inject suites still run.)

    querying an existing project under a foreign workspace_id (returns null). Cross-PROJECT isolation
    (the headline) is fully tested with two real projects.

    (status -> 'deleting') gated on countActiveRunsForProject==0 + exact-name confirmation + Inbox refusal.
    The batched purge job / cancel-first flow is a later task; delete here only sets the tombstone.

    `one_inbox` guarantees the singleton (verified: a second is_inbox insert raises 23505).
